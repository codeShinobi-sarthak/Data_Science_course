# Data Science Course

This repository contains hands-on learning material for Python, data analysis, visualization, machine learning, and deep learning.

## Repository Structure

- `01_project_1/` – Multi-part project notebooks and practice files
- `01_project_2/` – Data preparation and processing project
- `02_numpy/` – NumPy fundamentals and array operations
- `03_pandas/` – Pandas data manipulation and cleaning
- `04_matplotlib/` – Data visualization with Matplotlib and Seaborn
- `05_web_scraping/` – Web scraping with Requests and BeautifulSoup
- `06_scikit_learn/` – Introductory machine learning notebook
- `07_practical_ml_scikit_learn/` – Practical ML workflows (Iris + California housing)
- `08_deep_learning/` – Perceptron and MNIST neural network practice
- `_python_DSA/` – Python data structures and algorithms notebooks
- `_python (linkedIn)/` – Python learning exercises and reference files
- `_notes/` – Supplemental PDF notes and learning resources

## How to Use

1. Open notebooks (`.ipynb`) in Jupyter Notebook or JupyterLab.
2. Work through folders in numeric order for a progressive learning path.
3. Use project folders for end-to-end practice.

## Requirements

- Python 3.x
- Jupyter Notebook / JupyterLab
- Common data science libraries used across notebooks, such as:
  - NumPy
  - Pandas
  - Matplotlib
  - Seaborn
  - scikit-learn

## Notes

- Most content is notebook-based and intended for practice.
- Some folders include datasets, PDFs, and helper scripts.
